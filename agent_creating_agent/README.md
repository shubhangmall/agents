# Agent-Creating-Agent Experiments

This directory contains an experimental framework where AI agents are tasked with generating and refining new agents. It uses the `autogen_core` and `autogen_agentchat` libraries and demonstrates meta‑learning concepts and agent orchestration.

## Overview

- `agent.py` – base `RoutedAgent` implementation representing a creative entrepreneur that invents business ideas.
- `creator.py` – supervisory agent responsible for spawning workers.
- `world.py` – orchestrator that spins up a gRPC runtime, registers a `Creator`, and asks it to generate multiple agent ideas.
- `agent1.py` … `agent20.py` – sample worker agents produced during experimentation.
- `idea*.md` – markdown files containing outputs generated by each worker.

Agents in this sandbox are configured to bounce ideas off one another and refine concepts, illustrating how agents can collaborate and even create other agents programmatically.

## Installation

```bash
cd agent_creating_agent
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt  # install openai, autogen, etc.
```

> Make sure you have a `.env` file or environment variable containing `OPENAI_API_KEY`.

## Usage

1. Start the world:

    ```bash
    python world.py
    ```

2. The script will launch a gRPC host and worker, register the creator agent, and request ideas for `HOW_MANY_AGENTS` (default 20).
3. Each idea is written to `idea1.md` through `idea20.md`.
4. Inspect the generated `agent*.py` files and `idea*.md` outputs to understand agent behavior and meta‑generation logic.

## Extending

- Adjust `Agent.system_message` in `agent.py` to change personality or domain.
- Change `HOW_MANY_AGENTS` or add logic in `world.py` for more complex workflows.
- Use this structure as a starting point for workshops or research on agent-of-agent architectures.
